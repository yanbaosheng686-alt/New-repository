# 한중 양식 계산기 / 韩中双语简易计算器
## 목적 / 目的
간단한 웹 계산기로 기본 사칙연산을 수행하는 웹 애플리케이션입니다. 모든 화면 텍스트는 한국어와 중국어로 동시 표시합니다.
这是一个可以进行基础四则运算的网页计算器应用，页面所有可见文字同时使用韩文+中文双语展示，满足作业双语要求。

## 주요 기능 / 主要特点
1. 덧셈, 뺄셈, 곱셈, 나눗셈 사칙연산 / 加减乘除基础四则运算
2. 초기화, 지우기 기능 / 清空、退格删除功能
3. 버튼, 안내문구 모두 한중 병행 표시 / 按钮、提示文字全部韩中双语并行显示
4. 브라우저에서 바로 실행 가능, 별도 설치 불필요 / 浏览器直接打开运行，无需额外安装

## 실행 방법 / 运行方式
1. index.html 파일을 브라우저로 열기 / 用浏览器打开 index.html 文件
2. 숫자와 연산 버튼 클릭하여 계산 / 点击数字和运算按钮进行计算
3. C 버튼으로 전체 초기화, ← 버튼으로 한 글자 지우기 / C键清空全部，←键删除最后一位
